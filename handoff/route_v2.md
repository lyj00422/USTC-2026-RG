# Route v2 当前交接入口

当前自动化程序采用库存/槽位驱动循环。完整说明见同目录 `交接文档.md`。

关键约束：紫色固定左槽且最多一个；车辆最多三个方块；橙色动作完成后直接再次识别，不追加 `D20`；搭建后倒车 30 cm、左旋 180°；有紫色直接 `D330` 到取物区 1，无紫色复用 J2 到 J3 判断并检查紫色；`SUCTION,true` 保持到明确的 `SUCTION,false`；仅当紫色和橙色都识别不到时停止。

**路线自己的腿段**速度统一 fast80。**动作包不是**——包里的速度是自带值（抓取包 `v`/`D` 都是 20，搭建包沿用录制值），`forward_speed_limit: 80` 只是编译期对正 `vx` 的截断上限。别把包提速到 80 当成"改成标准值"。

**方块取用顺序 = 吸盘槽 → 右槽 → 左槽**（左槽固定紫块、留到最后封顶），由 `loop_strategy.py` 选包实现，包本身不判断。角色→包→层那张表见 `交接文档.md`「搭建动作」。

**舵机基准（2026-09-29）**：复位 id0 1840 / id1 1520 / id2 1500 / id3 1400；抓左槽 id0 **630**、抓右槽 id0 **1020**。id4 存在但从未被动作包使用。

⚠ **跑之前必须做**：抓取包里有 `D -12/-17/-15/-16 0 0 20`，而全仓库从无负 `forward_cm` 先例——**轮子离地先单发一条 `D -17 0 0 20` 确认是后退**，符号反了会顶进墙。另外 `D` **不能重发**（固件会重启移动，STOP 幂等、`D` 不幂等）。

底盘链路：保活由 `rg_runtime/chassis_link.py` 的 `ChassisLink` 负责，端口一打开就起心跳线程，
与 tick 无关（2026-09-29 重构，之前保活写在 tick 里，覆盖不到运行开头 20–40 秒的初始化静默——
存档 60 次运行的 10 次掉线全部落在运行前 90 秒）。参数 `chassis_heartbeat_*` 见 `config/route_v2.yaml`。

⚠ 两个已知缺口，见 `交接文档.md` 对应小节：取物后回线在橙色区走**单向**逻辑，方向推得出就没有摇摆兜底（没有第二道保险）；`PICKUP_2_RETURN_TO_LINE` 的 fault **没有**映射到 `FAULT` 状态，失败表现为原地静默 STOP 保持。
