# 橙色识别稳定性设计

## 目标与范围

根据本地橙色录像与现场 sweep 探针，提高近距橙色方块的连续识别率。生产改动只涉及视觉 profile 的颜色通道、橙色参数和对应检测器支持；不修改状态机、搜索动作、抓取动作、稳定帧数、紫色识别或 Tag 识别。

## 证据

- `20260916_130048_092165_recording.avi` 共 740 帧，当前 detector 接受 606 帧（81.9%），存在 25 段连续漏检，最长 12 帧。
- 漏检主要来自低饱和度浅橙色在 HSV 中色相不稳定，以及横移到画面边缘时可见轮廓面积降至约 93k~149k px。
- 单独降低面积到 100k 只能提升到 642/740；单独加宽 HSV 只能提升到 626/740。
- 补充 YCrCb 暖色通道 `[150,131,115]..[250,150,132]` 并将橙色最小面积设为 100k 后，命中 720/740（97.3%），剩余连续漏检最长 3 帧。
- 紫色视频、Tag3 视频和四段路线视频共 4431 帧在该组合下均为 0 命中。

## 方案

1. 在 `BlockVisionProfile` 增加默认空值的 `ycrcb_bands`，保证现有 profile 行为不变。
2. `ProfiledBlockDetector` 生成 YCrCb mask，并与现有 HSV/Lab mask 做并集；命中的诊断通道记录为 `ycrcb`。
3. 仅在 `orange_pickup_close` 配置 YCrCb 色带，并将 `area_px` 下限从 150000 调为 100000。
4. 保持橙色的 ROI、长宽比、高度、质心、底边、矩形度、近场填充、捕获窗口和 `confirm_frames: 3` 不变。

## 安全边界

YCrCb 只补全浅橙色/暖白目标的颜色覆盖；候选仍必须同时通过完整几何与近场门槛。其他 profile 未配置 YCrCb，因此不会改变紫色流程。面积下限只在橙色 profile 内调整，且仍高于本地负例中约 76k px 的最大杂色轮廓。

## 验证

- 单元测试先证明旧 detector 不认识仅命中 YCrCb 的浅橙色，再验证新增通道。
- 配置回归测试锁定橙色 YCrCb 色带、100k 面积下限及其他几何门槛不变。
- 运行橙色录像逐帧回放，要求至少 720/740 帧接受、最大连续漏检不超过 3 帧。
- 运行全部本地负例视频，要求 0 接受。
- 运行视觉相关测试与编译检查；全量测试若受工作树既有改动影响，单独报告而不越界修改。
