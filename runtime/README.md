# RoboGame Runtime

当前自动化程序是库存驱动的循环。车辆最多携带三个方块，库存固定记录为 `left_slot`、`right_slot`、`suction_slot`。

## 运行

```powershell
cd C:\Users\LJY\Desktop\RG\runtime
python -m pytest tests -q
python run_route_v2.py --dry-run --full --config config/route_v2.yaml
```

现场运行使用 `config/route_v2.yaml`。活动路线只使用 fast80。

## 库存规则

- 紫色最多一个，并且只进入左槽。
- 有紫色时，橙色依次进入右槽、吸盘槽。
- 没有紫色时，橙色依次进入左槽、右槽、吸盘槽。
- 取橙色的顺序是：识别、对中、抓取；动作包完成后直接识别下一个，或按库存返程。
- 车辆满三个方块后不再取橙色，回搭建区执行搭建。

## 路线循环

1. 起点按现有 J1/J2/J3 巡线到搭建区，默认速度为 80。
2. 首次携带一紫二橙到搭建区：先搭两层橙色，紫色留在左槽。
3. 搭建后倒车 30 cm、左旋 180°，持续巡线并复用 J2 到 J3 的到达判断。
4. J3 需要紫色时，执行当前搭建区到取物区 1 的既有路线；紫色已在车上时跳过 J3 紫色判断，直接执行 `D 330 cm` 到取物区 1。
5. 回取物区 1 按容量和视觉结果持续取橙色。橙色动作完成后不追加固定距离动作；满载或识别不到橙色就返程。
6. 回搭建区先用独立的 `build_occupancy` 视觉 profile 判断是否已有橙色层。搭建动作顺序始终是先放吸盘槽，再放右槽，最后从左槽取紫色（若存在）。动作包按 `data/route_v2_actions/catalog.json` 加载。

唯一业务停止条件是：J3 识别不到紫色并且取物区 1 识别不到橙色。车辆满载、一次识别失败、完成一轮搭建或紫色封顶都不能单独停止。

## 吸盘

`SUCTION,true` 一旦执行就保持吸附。动作包切换、复位占位、巡线和转弯都不能自动释放；只有明确的 `SUCTION,false` 指令可以关闭吸盘。
